Kubernetes Session 1 Setup

GDG Chapel Hill Kubernetes Learning Series









Budget 20-30 minutes. Do this before the session so we can spend our hour on Kubernetes, not installers. Stuck? Ask in the event chat or join 10 minutes early.

1. A Linux-like shell

  • Windows: use WSL 2 + Ubuntu. In PowerShell run wsl --install -d Ubuntu, restart if asked, then open Ubuntu and create a user. Run all commands below inside Ubuntu.
  • macOS / Linux: your normal terminal is fine.

2. Docker

  • Windows / macOS: install Docker Desktop. On Windows enable Settings → General → Use the WSL 2 based engine and Settings → Resources → WSL Integration → your Ubuntu distro, then Apply & restart and reopen Ubuntu.
  • Linux: install Docker Engine and make sure your user can run docker (docker group).

Check (inside Ubuntu on Windows). Both must run without a connection error:

docker version
docker ps

3. kubectl and kind

Install the latest stable release of each using the official instructions:

  • kubectl: kubernetes.io/docs/tasks/tools
  • kind: kind.sigs.k8s.io quick start

Optional: a tool-version manager such as mise can install both for you. If you use one, activate it for the shell you actually use (zsh vs bash).

Check:

kubectl version --client
kind version

4. Work in the Linux filesystem (WSL)

mkdir -p ~/k8s-learning && cd ~/k8s-learning

Keep files under ~, not /mnt/c/....

5. Optional: create the cluster early

kind create cluster --name k8s-learning
kubectl get nodes

You should see one node with STATUS Ready. Doing this ahead means the image download won't slow you down during the session.

Troubleshooting

SymptomFix
docker: command not found in Ubuntu Enable WSL Integration for your distro in Docker Desktop, apply, reopen Ubuntu
kind: command not found after install The tool is not on PATH for your current shell. Activate your version manager for zsh/bash and reload the shell
Cannot connect to the Docker daemon Start Docker Desktop and wait until the engine shows Running
Cluster creation very slow The first run downloads the node image. Create it early or use faster Wi-Fi
